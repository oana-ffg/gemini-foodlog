Build order and evidence gates

No surprises backlog

Every known task required for the hackathon MVP, grouped in intended build phases. Dependency links are authoritative where workstreams interleave. Mocked or local scaffolding is named as such and never closes a production capability. Acceptance criteria, verification, ownership, and blockers stay visible.

Official deadline: 31 Aug 2026 · 5:00 PM PT

The core is not done

North-star proof: an unfamiliar image must enter the deployed authenticated system, be analyzed by real Gemini through ADK, persist in Firestore and Cloud Storage, appear in the user UI, accept a correction, and help classify a later event. Infrastructure and mock fixtures do not substitute for this proof.

Status lifecycle

Backend tasks can reach Done after deployed smoke evidence. UI tasks move through browser smoke testing and then Needs Human Testing for Oana. Evaluation-only tickets remain in Needs Long Test until the agreed multi-day run is complete. A task does not begin before its dependencies are ready. If new work is discovered, it is added here before implementation begins.

Authoritative inputs: core idea, MVP architecture, credit-expiry runbook, and the official hackathon rules. Progress is task-count based, not an estimate of equal effort.
